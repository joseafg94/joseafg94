### Highlights

* Restaurant administration
* Categories & products
* Dynamic availability
* Public digital menu
* QR sharing
* Branding customization
* Mobile-first management
* Multi-tenant architecture

**Stack:** Next.js · React · TypeScript · Supabase · PostgreSQL · Tailwind CSS
